# Task: Full-page loading spinner during decryption

**Request:** Instead of flashing encrypted data on page reload, show a semi-transparent full-page loading spinner overlay until decryption completes.

## Sub-tasks

- [x] Update `PasswordGate.tsx`: add `pageLoading` state; show loading overlay immediately if key exists in sessionStorage (or already in memory); clear after `decrypt:unlocked` + 300ms delay (time for worker + React re-render); fall back to password form if no key found
- [x] Add CSS: `@keyframes spin`, `.page-loading-overlay`, `.page-loading-spinner` to `global.css`

## Notes

- `pageLoading` starts as `isEncrypted` (true for encrypted builds) so the overlay is in the initial SSR HTML — prevents any flash before hydration
- 300ms delay after `decrypt:unlocked` gives the web worker time to finish + React to re-render
- `decrypt:failed` clears loading and shows form immediately
