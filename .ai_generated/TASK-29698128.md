## Notes

- Astro 6 requires `src/content.config.ts` (not `src/content/config.ts`) and the new Content Layer API with `glob()` loaders.
- Content files must use `.md` extension — `.mdx` files show "No entry type found" in Astro 6 without `@astrojs/mdx`.
- Astro 6's glob loader normalizes entry IDs to lowercase (e.g. `01JX...` → `01jx...`), affecting URL generation for blog posts.
- esbuild/sharp require explicit build-script approval in pnpm 10; approved via `onlyBuiltDependencies` in pnpm-lock.yaml settings.
- Placeholder images are SVG (not JPG) since generating JPEG requires additional tools.
- All 30 Playwright E2E tests pass.
