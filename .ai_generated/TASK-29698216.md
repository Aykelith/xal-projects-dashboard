## Original request
Add encryption so the static site can be published publicly on GitHub without exposing project content, blog posts, task bodies, or images. Decrypt in-browser (client-only, no storage). Web Worker for images (decrypt-per-image + decrypt-all button).

## Design decisions
- AES-256-GCM via WebCrypto + PBKDF2 (300k iterations)
- Global salt in `public/enc/config.json`, unique IV per file
- Plaintext in project JSON: all fields except `home_description`
- Text content: encrypt body, keep frontmatter plaintext
- Descriptions: add `enc_body` frontmatter (body-only files get frontmatter added)
- Images: binary → base64 in JSON envelope, `.enc` extension replaces `.jpg`
- Decrypt-all: `forceDecryptAll` flag in React context
- Password re-entered per page load (no storage)
