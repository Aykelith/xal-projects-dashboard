## Key discoveries

### Playwright execution order
WebServer starts BEFORE globalSetup in Playwright v1.61.0. Confirmed by seeing
`[WebServer] The collection "posts" does not exist or is empty` before `Encrypting content...`.
Fix: pre-encrypt all test content in the Dockerfile RUN step.

### Astro Content Layer glob ID format
`glob({ pattern: '**/*.enc.md', base: '...' })` strips `.md` but keeps `.enc` in entry.id.
So `entry.id = 'xal-test-project/01jx0v2pk8abcdef0000000002.enc'` (not `.enc.md`).
The old regex `/(?:\.enc)?\.mdx?$/` required `.md` and failed to match `.enc` alone.
Fixed all occurrences to `/\.enc(?:\.mdx?)?$|\.mdx?$/`.
Files changed:
- src/pages/blog/index.astro
- src/pages/blog/[projectId]/[postId].astro
- src/pages/projects/[id].astro (3 regex occurrences + 1 description fname)

### Dockerfile pre-encryption
Added to Dockerfile after `COPY . .`:
```
RUN cp -r test-env/fixtures/data/. data/ && \
    rm -f data-encrypted/projects/xal-ai-projects.enc.json && \
    ENCRYPT_PASSWORD=testpass123 \
    ENCRYPT_SALT=e2e0e2e0e2e0e2e0e2e0e2e0e2e0e2e0 \
    node scripts/encrypt.mjs
```
This ensures pnpm build sees encrypted content. Also removes committed real project
from data-encrypted/ to avoid 31 projects showing up.
