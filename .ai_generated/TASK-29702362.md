# Task: Persist derived AES key in sessionStorage to avoid re-entering password on every page

## Request
User wants to avoid entering password on every page navigation. Derive an intermediary key and store it in sessionStorage. Real password must not be stored.

## Approach
- Make derived AES-GCM key extractable
- After successful unlock: `exportKey('raw', key)` → base64 → sessionStorage
- On mount: check sessionStorage → if found, reimport key and skip password gate
- sessionStorage clears when tab closes — acceptable security boundary
