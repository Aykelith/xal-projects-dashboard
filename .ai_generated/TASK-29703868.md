# Task: Clear stale session key on decrypt failure

**Request:** When decryption fails on client (e.g. files re-encrypted with new password), remove session key and re-prompt for password.

## Sub-tasks

- [x] `decryptWorker.ts`: add `clearKey()` — nulls `_key`, dispatches `decrypt:failed`
- [x] `EncryptedContent.tsx`: on decrypt error, call `clearKey()` instead of setting error state; always register `decrypt:unlocked` listener so it retries after re-auth
- [x] `PasswordGate.tsx`: listen for `decrypt:failed` → clear sessionStorage + show modal

## Notes

- Multiple `EncryptedContent` instances may all call `clearKey()` — idempotent, fine
- UX: show "🔒 Encrypted" (locked state) not "Decryption failed" when key is stale, since password gate will appear
