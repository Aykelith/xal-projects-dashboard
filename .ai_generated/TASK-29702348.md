# Encrypt all project JSON fields

## Request
When encrypted, fields in `data/projects` are not getting encrypted. Their values should get encrypted too.

## Analysis
Currently `scripts/encrypt.mjs` only encrypts `home_description` → `enc_home_description`.
Committed `.enc.json` files expose in plaintext: `title`, `stage`, `started_at`, `last_activity_at`, `last_task_id`, `last_post_id`.

`id` stays plaintext (required for routing in `getStaticPaths`).

Client-side impact: `ProjectsGrid` sorts/filters by `stage`, `last_activity_at`, `started_at`. These must be decrypted first. `ProjectCard` displays `title`, `stage`, dates. `[id].astro` renders title/stage/dates in static HTML.
