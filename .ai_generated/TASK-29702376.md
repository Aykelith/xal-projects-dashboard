# Fix: project description not showing on project page

## Request
User created a description in `data/content/descriptions/`, ran encrypt, but description doesn't appear on the project page.

## Root Cause
Astro's glob loader applies `github-slugger` to path segments after stripping `.md` extension.
File `xal-ai-projects.enc.md` → strip `.md` → `xal-ai-projects.enc` → githubSlug → `xal-ai-projectsenc` (dot removed).

The lookup in `[id].astro` uses:
```js
d.id.replace(/(?:\.enc)?\.mdx?$/, '') === project.id
```
But `d.id` = `xal-ai-projectsenc` has no extension → regex matches nothing → ID stays as-is → never equals `xal-ai-projects`.

## Fix
Use `d.filePath` instead of `d.id` for description lookup.
